# Waiting Check

Review delegated work and decide whether each item still waits, needs a nudge, or is done.

## Steps

1. Read Waiting For with the profile's list tool.
2. Show each item, its owner, and its age when the backend exposes an age or modified date. Otherwise mark age unknown.
3. Offer three outcomes:

| Response | Change |
|----------|--------|
| keep waiting | Leave unchanged |
| nudge | Add a follow-up next action for the owner |
| done | Complete the waiting item |

Confirm before completing. Follow the profile's capabilities for undo and delete.

The check is complete when every waiting item is unchanged, has a follow-up, or is completed.
