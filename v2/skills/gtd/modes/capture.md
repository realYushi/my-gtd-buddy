# Capture

Put work into Inbox. Do not organize it yet.

## Steps

1. Resolve the Inbox name from the active profile.
2. Create one item per capture with the profile's capture tool. In manual mode, ask the user to add it and confirm.
3. Add a due date only when the profile supports due dates and the user gave one.
4. For a list of items, create each separately and confirm as one batch.

Capture is complete when every named item exists exactly once in Inbox.

Captures are not processed items. Do not add them to completion or processing totals.
