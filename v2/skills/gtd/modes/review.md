# Weekly Review

Five parts. Move at a pace that fits the available history.

## Start

Read counts, recent completions, stale items, projects, and waiting items when the profile supports the queries. In manual mode, ask for the numbers.

State the review window explicitly. A seven-day completion count is a **snapshot**, not a weekly total.

## Part 1: Wins

Show completed items for the last seven days. Ask for the biggest win. Acknowledge briefly.

## Part 2: Stuck

Show items untouched for seven or more days when age is available. Otherwise ask which items feel stuck.

For each: keep, move to Someday, or delete. Confirm deletes.

## Part 3: Projects

List projects. For each, verify at least one next action. If the backend links tasks to projects, use that link. Otherwise ask the user to confirm the relationship.

## Part 4: Waiting

Review Waiting For. Keep, nudge, or complete each item.

## Part 5: Mind Sweep

Ask what is still in the user's head. Capture each item to Inbox.

## Close

Summarize the five parts and ask for the next week's focus. Store the focus only in a place the profile or user provides; do not invent a state store.

The review is complete when all five parts are covered or explicitly skipped. Do not add completion snapshots together or present them as weekly completions.
